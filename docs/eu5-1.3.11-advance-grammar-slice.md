## 设计与验收标准

1. `research_advance` 仅登记为 country-scope effect，RHS 必须是
   `advance_type:<identifier>`；裸 key 或 block 形态保持 RED。
2. `has_advance` 仅登记为 country-scope trigger，RHS 必须是裸
   `<identifier>`；`advance_type:` 前缀或 block 形态保持 RED。
3. 二者位于错误 trigger/effect 侧时得到 `WRONG_DOMAIN`；位于可静态确定的
   location scope 时得到 `INVALID_CURRENT_SCOPE`；错误 RHS 得到
   `INVALID_SCALAR_VALUE`。
4. Java profile/validator 测试和 CLI smoke 同时覆盖 GREEN 与上述失败闭锁；当前完整
   Phase 2 fixture 必须得到 syntax=0、semantic=0。
