# EU5 1.3.11 国家首都 Region scope 链

## 目标、范围与非目标

在已锁定的 Steam Build `24187685` / `eu5.exe` SHA-256
`c0db888da5e132cd6ab50c2c531c7cae419488bea0054cf8ac348616332683ef`
下，补充 Open Kaishek 事件文件静态 schema，使 Tusi 验收夹具
`xcrt_acceptance.11.option.c:GYT.capital.region` 不再被误报为
`UNKNOWN_OPCODE`。仅扩展国家 scope 左值的 `c:<tag>.capital` 与
`c:<tag>.capital.region` 两个有限链，现有 `c:<tag>`、地点 scope、正式产品
interaction/scripted trigger 与其他游戏 profile 不变。

此切片不验证 GYT 的首都是否存在、Region 身份、donor 枚举结果、
`every_in_list` 效果或实际运行；这些需要锁定 build 的隔离实机证据。

## 设计与验收

1. `c:<tag>`、`c:<tag>.capital`、`c:<tag>.capital.region` 均须带 RHS
   script block，内部仍递归验证 trigger/effect；任意额外 dotted 后缀继续
   `UNKNOWN_OPCODE`。这不是扩张所有 dotted scope 的通配规则。
2. 完整验收夹具应是 syntax=0、semantic=0；正式 scripted trigger 和
   country interaction 仍为 0 诊断。
3. 负向测试证明非法后缀与 scalar scope 左值失败闭锁；仓库级静态验收
   通过。`VALIDATED` 仍仅代表本 schema 切片通过。
