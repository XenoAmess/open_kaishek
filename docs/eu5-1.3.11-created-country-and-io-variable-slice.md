为 Steam Build `24187685` / `eu5.exe` SHA-256
`c0db888da5e132cd6ab50c2c531c7cae419488bea0054cf8ac348616332683ef`
补齐殖民 Region 转移验收夹具所用的三项静态语法：

- `create_country_from_location` 内的 `set_country_rank` effect；
- `international_organization:<id> = { ... }` 左值 scope；
- 上述 scope 内的 `set_variable` effect（兼容 scalar 与参数块形态）。

本切片不验证 country rank、国际组织或变量是否在运行时存在，不模拟新建国家、
HRE 状态或变量生命周期；`VALIDATED` 只表示 exact-build 静态形态和
trigger/effect 位置通过，行为仍须实机与日志证据。

## 设计与验收标准

1. 只接受 `international_organization:<ASCII id>` 的有限左值 scope，并要求
   RHS 是 script block；任意额外 dotted 后缀或 scalar 左值失败闭锁。
2. `set_country_rank`、`set_variable` 登记为 effect；在 event trigger 中出现时
   报 `WRONG_DOMAIN`。
3. `set_variable` 的参数块保持不透明参数对象；其外层 effect 仍被类型检查。
4. 完整 Phase 2 fixture 必须 syntax=0、semantic=0；正式 scripted trigger 和
   country interaction 不回退；未知 opcode 继续 RED。
