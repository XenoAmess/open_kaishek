## 设计与验收标准

1. `NAND` 是递归 trigger 容器，不登记为 effect opcode；其中未知词汇仍失败闭锁。
2. `every_current_war` 是递归的 effect-side iterator，不是不透明参数块；
   `limit` 内 trigger 与其后的 effect 分层验证。
3. `country_exists`、`any_war_participant` 在 option effect 侧直接出现必须报
   `WRONG_DOMAIN`；`declare_war`、`white_peace` 在 event trigger 中必须报错。
4. 两份完整验收 fixture 均须 syntax=0、semantic=0；两份正式产品脚本不回退；
   任意未登记 opcode 继续 `UNKNOWN_OPCODE`。
