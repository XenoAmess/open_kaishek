# Europa Universalis V 1.3.11 / Build 24187685 静态 profile

## 目的与边界

eu5-1.3.11-build-24187685 是面向 xenoamess.colonial_region_transfer 0.2.0
的受限静态 profile。它绑定 Steam Build 24187685 与 eu5.exe SHA-256
C0DB888DA5E132CD6AB50C2C531C7CAE419488BEA0054CF8AC348616332683EF，并覆盖该
产品实际使用的 country_interactions 和 scripted_triggers 方言。

当前覆盖：

- every_subject 直属候选枚举、is_subject_of 关系复核，以及 building、pop、army
  非领土对象排除。
- exists = capital 和 scope:recipient.capital.region 地理锚点。
- any_location_in_region 的 count 上界、is_subject_type = tusi 与 15 地点上限分支。
- add_to_list 快照、list_size 效果侧复核、every_in_list 和
  change_location_owner。
- 原版 give_location_to_subject、move_subject_capital、subject type readme、
  colonial_nation、state_bank、trade_company 的精确 SHA-256 证据。
- `in_game/events/*.txt` 的 country-event 声明、可重复 option、option 条件/效果、
  规范 `location:<id>` 与 `c:<tag>` scope、建国/建筑国家混合块和 Tusi
  gate 诊断；原版事件依据与边界见
  [EU5 事件语法切片](eu5-1.3.11-event-grammar-slice.md)。
- `c:<tag>.capital`、`c:<tag>.capital.region` 的有限左值 scope 链；
  原版完整左值例子缺失，因此此组合是静态推断，边界见
  [国家首都 Region scope 链](eu5-1.3.11-country-capital-region-scope.md)。
- 验收夹具的 `NAND` 互补条件，以及最小建国/战争 trigger、effect 与 iterator；
  exact-build 依据和非运行时边界见
  [NAND 与战争验收夹具切片](eu5-1.3.11-nand-war-fixture-slice.md)。

未登记 opcode 继续产生 UNKNOWN_OPCODE。该 profile 不实现 EU5 runtime handler，
也不把解析或静态 schema 通过称为运行时认证；互动可见性、所有权变更、土司最终地点数、
生命周期、存档重载与 Workshop 投影仍须由锁定 build 的隔离简中实机验收证明。

## 使用

    java -jar kaishek-cli/target/kaishek-cli-0.1.0-SNAPSHOT.jar validate
      --profile eu5-1.3.11-build-24187685 --file <script.txt>
